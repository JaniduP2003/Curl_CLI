cut -d: -f2- whyy:::

tr -d '\r' why ::: 
    Different operating systems use different combinations for “end of line”:

    | System            | End of line character(s)             | Example            |
    | ----------------- | ------------------------------------ | ------------------ |
    | **Linux / macOS** | `\n` (line feed only)                | `"Hello\nWorld"`   |
    | **Windows**       | `\r\n` (carriage return + line feed) | `"Hello\r\nWorld"` |
    
        So Windows puts two characters at the end of each line instead of one. SO IT REMOVES /r

HOW THE ARGUMENTS ARE PASSED IN .SH

💬 Example

./postman-cli.sh POST https://api.test.com/users "" '{"name":"Janidu"}' raw

The script does this:

    Sees POST → okay to send body ✅
    Type is raw → send as-is ✅
    No Content-Type header? → add Content-Type: application/json automatically 🧠
    Body: {"name":"Janidu"} → goes straight into curl’s --data-raw.

the code ;::

                                                # Decide how to send the body
                                                send_body=false
                                                send_raw=false
                                                if { [ "$METHOD" = "POST" ] || [ "$METHOD" = "PUT" ]; } && [ -n "$BODY" ]; then
                                                    case "$BODY_TYPE" in
                                                        raw)
                                                            send_body=true
                                                            send_raw=true
                                                            # For raw, default to JSON if not specified
                                                            if ! $has_content_type; then
                                                                HEADERS=$(printf "%s\n%s" "$HEADERS" "Content-Type: application/json")
                                                                has_content_type=true
                                                                ct_value="application/json"
                                                            fi
                                                            ;;
                                                        none)
                                                            send_body=false
                                                            ;;
                                                        *)
                                                            # Fallback heuristics when type not specified
                                                            send_body=true
                                                            if $has_content_type; then
                                                                ct_lower=$(echo "$ct_value" | tr 'A-Z' 'a-z')
                                                                if [[ "$ct_lower" != application/x-www-form-urlencoded* ]]; then
                                                                    send_raw=true
                                                                fi
                                                            else
                                                                # If body looks like JSON, set CT and use raw
                                                                if [[ "$BODY" =~ ^[[:space:]]*\{ ]] || [[ "$BODY" =~ ^[[:space:]]*\[ ]]; then
                                                                    HEADERS=$(printf "%s\n%s" "$HEADERS" "Content-Type: application/json")
                                                                    has_content_type=true
                                                                    ct_value="application/json"
                                                                    send_raw=true
                                                                fi
                                                            fi
                                                            ;;
                                                    esac
                                                fi 

while IFS= read -r header; do

    Loops through each line in $HEADERS and assigns it to the variable header.
    IFS= → prevents Bash from splitting the line by spaces (we want the whole line).
    -r → stops Bash from treating backslashes \ as special characters.
    So each iteration of the loop handles one header line.
